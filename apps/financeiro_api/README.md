## financeiro.api


### Construir as imagens
```
docker-compose build
```

### Iniciar os containers em background
```
docker-compose up -d
```

### Verificar se os containers estão rodando
```
docker-compose ps
```

### Para parar a aplicação:
```
docker-compose down
```

### Para ver os logs:
```
docker-compose logs -f
```
