# financeiro.app

Este projeto é uma aplicação de controle financeiro desenvolvida com Vue.js, Vuex e Vuetify. Uma aplicação simples que permite o gerenciamento de receitas e despesas, com funcionalidades de identificação de despesas com base no extrato bancário

## Project setup
```
yarn install
```

## Docker build
```
docker build -t financeiro-app .
```

## Docker run
```
docker run -p 8098:80 financeiro-app
```
